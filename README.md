
# Calculadora de Orçamentos

Primeiro projeto da minha formação em
Engenharia de Inteligência Artificial.

## Tecnologias
- Python 3.12
- Streamlit
- Unittest
- Git e GitHub

## Funcionalidades
- Cálculo de área em m²
- Cálculo de preços por quantidade
- Desconto automático de 5% acima de R$ 200
- Valor mínimo de pedido de R$ 30
- Interface web
- Testes automatizados

## Como executar

Instalar as dependências:

python -m pip install -r requirements.txt

Iniciar a aplicação:

python -m streamlit run app.py

## Executar os testes

python -m unittest test_calculos -v

## Objetivo

Projeto educacional para praticar Python,
funções, programação modular e testes.
